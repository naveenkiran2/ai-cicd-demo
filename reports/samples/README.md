# Sample reports

These were generated by real runs of `python -m ai_bot.demo --scenario <name> --approve --export-samples`, with
`NO_COLOR=1` and `--approver demo.approver`. They let you browse a complete set of outputs without running
anything. To regenerate them, run the same command again (it overwrites the folder for that scenario).

| Folder | Contents |
|---|---|
| `success/run/` | Green run: `run.json`, logs, JUnit, artifact + manifest, `bot/diagnosis.md` (release-readiness report) |
| `failure/run/` | Unit-test failure: diagnosis, `bot/remediation_plan.json`, `bot/remediation/` (safety checks, backup, patch, targeted validation, audit trail, final report), `bot/validation.json` |
| `failure/rerun/` | The full pipeline rerun triggered by the bot (all PASS) |
| `partial/run/` | Late-stage (integration/deployment) failure and its targeted repair |
| `partial/rerun/` | The full rerun after the targeted stage passed |
| `*/terminal-output.txt` | The exact terminal transcript of the demo |

Start with `failure/run/bot/diagnosis.md` and `failure/run/bot/remediation/final_report.md`.

The `workspace/` and `staging/` source snapshots are left out to keep the samples small.
